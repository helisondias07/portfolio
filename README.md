# Helison Dias - Portfolio

Portfolio pessoal desenvolvido com Next.js, TypeScript e Tailwind CSS.

[helisondias.vercel.app](https://helisondias.vercel.app)

## Sobre

Desenvolvedor Fullstack com experiência em React, Next.js,
TypeScript, Vue.js, Angular e Node.js. Este portfolio reúne cases de
e-commerce, experiência com a plataforma Wake, automação com IA
e informações de contato profissional.

## Stack

- **Framework:** Next.js App Router
- **Linguagem:** TypeScript
- **Estilo:** Tailwind CSS
- **Animações:** Framer Motion
- **Interações:** Framer Motion + carrossel customizado
- **Ícones:** Lucide React + Simple Icons
- **Tema:** next-themes
- **Deploy:** Vercel

## Rodando localmente

```bash
git clone https://github.com/helisondias/portfolio
cd portfolio
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no browser.
